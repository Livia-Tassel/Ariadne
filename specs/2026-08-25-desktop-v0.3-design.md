# Ariadne v0.3 设计：可独立运行的桌面预览版

日期：2026-08-25
状态：当前实现基线

## 目标

用户不再需要知道 Python、uv、CLI 或 localhost。双击 Ariadne 后：

1. 看见项目启动页；
2. 用系统目录选择器选择一个研究目录；
3. 空目录自动初始化，已有 Ariadne 目录直接打开；
4. 在同一个原生窗口完成实验闭环；
5. 下次启动可从最近项目进入，也可随时切换研究目录。

## 架构

- **原生窗口**：pywebview；macOS 使用系统 WKWebView，不捆绑 Chromium。
- **目录选择**：系统文件夹选择器，不在网页中猜测或手填路径。
- **业务内核**：继续使用 Python 领域函数与 append-only `runs.jsonl`。
- **本地服务**：每次打开项目时随机绑定 `127.0.0.1` 端口，仅供应用窗口访问。
- **最近项目**：只在系统 Application Support 中保存路径与最后打开时间；实验数据始终留在用户选择的目录。
- **macOS 打包**：py2app 生成 onedir `.app`，包含 Python、依赖、界面资源和应用图标。

桌面壳不复制判定、事件或信念逻辑。浏览器 GUI、桌面应用和 CLI 仍是同一个产品内核的三个入口。

## 目录选择规则

- 空目录：直接初始化。
- 已含 `runs.jsonl`：按 Ariadne 项目打开。
- 非空但不是 Ariadne 项目：先用系统确认框说明会新增哪些文件；取消则不写任何内容。
- 最近项目已被移动或删除：显示可行动提示，不重新创建旧路径。

## 数据位置

项目目录由用户选择，包含：

```
runs.jsonl
config.toml
logs/
board.md       # 可重建
beliefs.md     # 可重建
```

macOS 最近项目列表位于 `~/Library/Application Support/Ariadne/recent-projects.json`。它不是实验数据的一部分，损坏或删除不会影响项目。

## 发布边界

v0.3 交付本机可双击运行的 `.app` 与可重复构建脚本，但还不是公开发行版：

- 尚未使用 Apple Developer ID 签名和公证；
- 尚未实现自动更新；
- 当前构建是 Apple Silicon 架构；正式发布需在目标最低 macOS 上构建并补 universal2/Intel 验证；
- Windows 需要在 Windows 构建机上生成并验证安装包。

## 验收

- 双击 `.app` 不出现终端窗口；
- 首屏目录选择、非空目录确认与最近项目可用；
- 选中目录后在同一窗口加载工作台；
- 可从工作台切换到另一个目录；
- 关闭窗口会停止项目本地服务；
- `.app` 移到仓库外后仍能启动，证明不依赖源码或开发虚拟环境。
