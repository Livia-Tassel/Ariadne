# Ariadne v0.2 设计：本地 GUI 可用版

日期：2026-08-25
状态：当前实现基线

## 1. 版本目标

v0.2 的目标不是给 CLI 再包一层皮，而是让没有终端工作流的科研人员也能完整跑通一次：

```
填写研究方向与假设 → 设计变量/指标表 → 填预测 → 录结果 → 看差异 → 复盘 → 沉淀信念
```

完成标准：用户进入一个本地网页后，不编辑 YAML、不手写 JSON、也不需要理解事件模型，就能完成上述闭环。CLI 保留为自动化与高级用户入口，但不再承担主要产品体验。

## 2. 产品形态

当前采用本地 Web GUI：

- `ari gui -p <project>` 在 `127.0.0.1` 启动服务并打开浏览器；
- 首次打开时自动创建项目骨架，不要求先运行 `ari init`；
- HTML/CSS/JavaScript 与 Python 服务一起打包，不依赖 CDN，断网可用；
- 服务只绑定本机，直接读写用户指定项目中的 `runs.jsonl`；
- 后续桌面版使用同一套 GUI 与服务接口，由 Tauri、PyWebView 或原生壳负责窗口、安装包、自动更新与系统密钥存储。

选择本地 Web 而不是立刻上桌面壳，是为了先验证最重要的交互，而不是提前承担签名、公证、更新与跨平台打包成本。

## 3. 信息架构

界面分为五个工作区：

1. **总览**：批次、run 判定、待复盘数量与噪声提示；
2. **新实验**：研究方向、假设、变量维度、指标规格和预测表；
3. **录入结果**：选择批次/run/seed，按该批次指标填写实测值；
4. **复盘**：只展示尚未处理的 SURPRISE，并排呈现预测、实测和原始理由；
5. **信念**：展示在册、加强、动摇和已推翻的信念。

GUI 中不照搬 CLI 的“两次打开编辑器”交互。实验设计与预测仍然分两步，但保留在同一个页面：第一步生成 run 矩阵，第二步在横向可比较的表格中填写预测。

## 4. 数据与领域边界

`runs.jsonl` 继续是唯一真相来源。GUI 不引入第二套数据库或可编辑的派生状态。

v0.2 只扩展 `batch_opened.payload`：

```json
{
  "research_direction": "小数据集上的视觉模型正则化",
  "hypothesis": "在同等训练预算下……"
}
```

旧项目没有 `research_direction` 时按空字符串读取，schema 版本无需升级。`board.md`、`beliefs.md` 和 GUI 状态都从事件流重新投影。

HTTP 层只做三件事：输入校验、调用领域函数、追加事件。判定、聚合、run key 规范化、信念 ID 等规则仍只有一份实现。

## 5. v0.2 功能范围

必须完成：

- GUI 自动初始化项目；
- 动态添加/删除变量维度和指标；
- 根据笛卡尔积预览 run，并填写每个 run 的预测、置信度和理由；
- 手工录入单个 run/seed 的结果，阻止同一 seed 被无提示覆盖；
- 看板展示预测、聚合实测与 CONFIRMED/SURPRISE/NOISY 等判定；
- 在 GUI 中完成 run 级复盘、添加/更新信念，以及 batch 收口；
- 所有写操作失败时在原页面展示可行动的错误，不丢表单内容；
- 窄屏可用，完整离线工作。

明确不放进本版本：

- LLM 日志抽取、Excel 导出与自由问答；
- 多项目资料库、账号、云同步和多人协作；
- 原生安装包、代码签名、自动更新；
- 在线托管版。

AI 定性预测与复盘追问已经存在于领域层，但 v0.2 GUI 首先保证离线主闭环稳定。接入 GUI 时必须保持“用户预测先落盘，AI 判断后出现”的顺序。

## 6. API

接口只服务本机页面，不承诺公共兼容性：

- `GET /api/state`：完整派生状态；
- `POST /api/runs/preview`：校验变量并生成规范化 run key；
- `POST /api/batches`：锁定设计与预测；
- `POST /api/results`：追加手工结果；
- `POST /api/reviews`：写 run 级复盘与信念事件；
- `POST /api/batches/close`：写 batch 级收口。

成功统一返回 `{ "ok": true, ... }`，校验失败返回 4xx 与 `{ "ok": false, "error": "..." }`。页面每次写入成功后重新读取 `/api/state`，不在浏览器里维护另一套权威状态。

## 7. 发布路线

1. **v0.2 本地 GUI**：验证信息架构、表格填写摩擦和完整闭环；
2. **v0.3 桌面预览版**：封装窗口、项目选择器、系统 keychain、安装包；
3. **v0.4 可分发测试版**：macOS/Windows 签名、自动更新、崩溃恢复与数据备份；
4. 只有本地版被持续使用后，再决定是否做云同步与协作。

## 8. 验收

- 领域与 API 自动测试全绿；
- 浏览器中从空项目完整走通一次闭环；
- 刷新页面后状态与写入前一致；
- 断网时页面和所有非 AI 功能可用；
- `runs.jsonl` 仍可由旧 CLI 读取，旧项目也可直接由 GUI 打开。
